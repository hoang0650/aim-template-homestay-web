# Mây Homestay — web template

Landing page đặt phòng homestay (HTML / CSS / JS thuần), dùng làm template mẫu cho **AI Markets Builder**.

- Hero ảnh lớn, danh sách phòng có lọc theo số khách
- Tiện ích, đánh giá khách
- Form đặt phòng tính tổng tiền theo số đêm, kiểm tra dữ liệu
- Responsive, menu mobile

## Cấu trúc

```
index.html   trang chính
styles.css   giao diện
app.js       dữ liệu phòng + tương tác
```

## Chạy thử

Mở `index.html` bằng trình duyệt, hoặc đăng lên AI Markets: **Đăng bán → Template web → Từ GitHub → Build**.
